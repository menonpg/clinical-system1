Kev

A family of small open decision models built on Qwen3.5 and Qwen3.8 decoders. Kev turns a causal language model into a question-answerer: a LoRA adapter and a pointer head read the prefill, and nothing is generated. Its API matches TypeSafe's System One, the API behind the hosted "Jev" model.

Architecture

  • Pointer head. It scores each option's </opt> hidden state against the question's <decide> state. <decide> comes last, so it can see every option.
  • Isolation. Asking questions together or one at a time gives the same probabilities (within 4e-6 in fp32). Option order can still matter within a question.
  • Calibration. One fitted temperature per checkpoint: 0.8B 2.35, 4B 2.41, 9B 2.30, 27B 1.38. On new sources it takes Kev-9B's ECE from 0.106 to 0.042.

Training

The base set is decision-v7: 10,000 examples from ten public datasets (BoolQ, MNLI, AG News, Banking77, SST-5 and others), 896 generated policy examples and 1,680 rule-structure examples. Training runs for two epochs with cross-entropy, LoRA rank 16, and learning rate 1e-4 (0.8B) or 5e-5 (4B/9B). Short follow-up fine-tunes then add day-count and missing-evidence cases. The run log records about 110 controlled trials, which set the recipe. kev.train --init_from jaredpalmer/kev-4b fine-tunes from a released checkpoint, which keeps its general skill.

Each cell is dev / test. At a 5% error budget Kev can automate 0.45–0.57 of decisions, against Jev's 0.70. Known weaknesses: knowledge questions (MMLU 0.74 for 9B), day-precision date arithmetic (mitigated by KEV_DATE_FACTS=1), and states longer than the 384 training tokens.

Running it locally (Apple Silicon)

cd upstream/kev && uv sync --extra serve
uv run --extra serve python -m kev.serve --run jaredpalmer/kev-4b   --port 8009
uv run --extra serve python -m kev.serve --run jaredpalmer/kev-0.8b --port 8019

curl -s localhost:8009/v1/systemone -H 'content-type: application/json' -d '{
  "state": "68 y/o man, 1 ppd x 40 years, quit 3 years ago.",
  "model": "kev-latest",
  "questions": {"py": {"type": "noul",
    "instructions": "Does the patient have a smoking history of at least 20 pack-years?"}}}'

On our M1 Max (64 GB), Kev-4B serves in bf16 through MLX. The first run downloads about 8 GB of base weights. The server binds to 127.0.0.1, so notes never leave the machine. Set KEV_API_KEY to require a bearer token.
