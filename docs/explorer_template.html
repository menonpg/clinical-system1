Checklist Screening Explorer

These are recorded answers from local decision models, and one generative LLM for comparison, run against USPSTF screening checklists. Each note gets a probability for every criterion, and the product of those probabilities is P(eligible). Drag the threshold to choose how confident the model must be before a note is decided automatically. Every note below that threshold goes to a clinician.

These notes are synthetic or hand-written, not real patients. This is a research prototype and not for clinical use.
