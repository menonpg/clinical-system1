Reproduce the study

Everything runs on one Apple Silicon laptop (we used an M1 Max with 64 GB), with no cloud calls after the first model download. A CUDA box works too: change --device.

1 · Environments

brew install uv
git clone https://github.com/NandhaKishorM/laya upstream/laya
git clone https://github.com/jaredpalmer/kev  upstream/kev

# Laya (Python 3.13)
uv venv --python 3.13 upstream/laya/.venv
uv pip install --python upstream/laya/.venv/bin/python -e "upstream/laya[serve]"

# Kev (uv project, MLX on Apple Silicon)
(cd upstream/kev && uv sync --extra serve)

# Generative baseline
ollama pull gemma4

2 · Data

# TREC CT 2021 topics and qrels, then 600 balanced pairs with ClinicalTrials.gov criteria
curl -sLo data/trec_ct/topics2021.xml https://www.trec-cds.org/topics2021.xml
curl -sLo data/trec_ct/qrels2021.txt  https://trec.nist.gov/data/trials/qrels2021.txt
python3 experiments/prep_trec.py

# USPSTF vignettes are generated deterministically on first use (seeds fixed in run_checklists.SPLITS)

3 · Serve Kev

(cd upstream/kev && uv run --extra serve python -m kev.serve --run jaredpalmer/kev-4b   --port 8009) &
(cd upstream/kev && uv run --extra serve python -m kev.serve --run jaredpalmer/kev-0.8b --port 8019) &

4 · Run

L=upstream/laya/.venv/bin/python
$L experiments/run_checklists.py --backend laya          # E1, Laya EN zero-shot
$L experiments/run_checklists.py --backend laya-ml       # E1, Laya multilingual
python3 experiments/run_checklists.py --backend kev4b
python3 experiments/run_checklists.py --backend kev08b
python3 experiments/run_checklists.py --backend ollama:gemma4:latest

$L experiments/run_trec.py --backend laya-ml8k           # E2
python3 experiments/run_trec.py --backend kev4b
python3 experiments/run_trec.py --backend ollama:gemma4:latest

# E3: fine-tune Laya on template family A (MPS, ~1-2 h), evaluate on family B
$L experiments/finetune_laya.py --epochs 2 --out runs/laya-clinical
$L experiments/run_checklists.py --backend laya-ft:runs/laya-clinical

$L experiments/latency.py                                # uncontended latency
$L experiments/analyze.py                                # results/summary.json + summary.md
$L experiments/figures.py                                # docs/figures/*.svg

Every runner appends to its results file and skips finished items, so an interrupted run resumes where it stopped.
