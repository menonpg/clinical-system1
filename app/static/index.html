Clinical System One

Local checklist screening with calibrated decision models. Notes never leave this machine. Research prototype, not for patient care.

Criteria: one yes/no question each. "Required" is the answer eligibility needs. Edit freely.

Results appear here: a probability for each criterion, the combined eligibility, and whether the case is safe to auto-decide or needs a clinician.

Screens many notes with the checklist, model and settings from the first tab. Paste one note per line, or JSONL with a text field.

The checklist on the first tab, as code. The same request works against a Kev server (TypeSafe System One API) or in-process with Laya.
